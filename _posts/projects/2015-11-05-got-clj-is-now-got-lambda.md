Got.clj, the Clojure meetup in Gothenburg I help organise, has a new name: Got.λ, the Göteborg
Functional Programming Group. We've been meeting since 2012, and the topics have already gone beyond
Clojure, like this spring's intro to functional programming in Python, Haskell and Clojure. The new
name just makes it official: if it's functional, it's welcome.

Many of our meetups are hands-on, and the code ends up in our GitHub organisation. Some of the things
we've created together:

- [junebot](https://github.com/got-lambda/junebot), an online multiplayer game in Clojure.
- [sudoku-core-logic](https://github.com/got-lambda/sudoku-core-logic), a Sudoku solver using core.logic.
- [raspberry-storm](https://github.com/got-lambda/raspberry-storm), a Storm topology meant to run on a bunch of Raspberry Pis.
- [twitter-bot](https://github.com/got-lambda/twitter-bot), a bot that retweets mentions of Got.clj.
- [logo](https://github.com/got-lambda/logo), our logo, old and new.

Join us on [Meetup](https://www.meetup.com/got-lambda/), and find the code on GitHub:
[got-lambda](https://github.com/got-lambda)
